#  Ganesh Chaturthi — Interactive Web Experience

A modern and interactive web experience created to celebrate **Ganesh Chaturthi 2026** in a unique digital way.
The website combines animations, video, interactive elements, and a simple spiritual experience to make the celebration more engaging.

## Features

*  **Welcome Experience** — A cinematic welcome video/animation when the user enters.
*  **Personalized Welcome** — Greets the user using their entered name.
*  **Ganesh Chaturthi Countdown** — Displays the upcoming festival date.
*  **Do Pooja** — Users can interact with the website and perform a virtual pooja.
*  **Feedback Page** — Users can share their thoughts and feedback about the experience.
*  **Modern UI & Animations** — Designed with smooth transitions and interactive visual effects.
*  **Responsive Design** — Built to work across different screen sizes.

##  Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd ganesh-chaturthi
```

### 2. Start the Backend

```bash
cd backend
npm install
node server.js
```

### 3. Start the Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Then open the local URL provided by Vite.
